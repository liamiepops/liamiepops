**[Langsammm](https://addons.mozilla.org/en-US/firefox/addon/langsammm/)**. A Firefox extension that slows music by semitones with the voices left intact. Slowing normally drags vocal resonance down with the pitch and singers sound slurred. Langsammm puts that back. Real-time formant-preserving pitch shifting in the Web Audio API, published to addons.mozilla.org.
